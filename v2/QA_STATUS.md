# V2 preview QA and known limitations
Previous commit 38a2ab2: dependency installation, TypeScript, lint and four unit tests passed in GitHub Actions; Expo doctor failed only unsupported android.supportsRTL. Removed in newer commit; revalidation required. No device tests, live RLS tests, performance measurements, Google OAuth integration or migration rehearsal yet.
Local preview uses SQLite key-value storage; no account isolation on shared devices, no cloud sync. Do not enter sensitive or production data. Auth is not a route guard. Weather uses Open-Meteo free endpoint only for noncommercial evaluation. Prayer times use AlAdhan calculation methods 5/23; verify local authority. Prayer reminders only for current day, default notification sound. No full licensed adhan, no persistent exact alarm, no background Arabic speech. Basic command parsing, not full conversational intelligence. No admin APK or complete RTL/LTR localization. UI is not pixel-verified against reference. Separate package and prerelease only.
